🔐 Как работает Multi-Tenancy:

  • X-Company-ID: HTTP header, который идентифицирует текущую компанию
  • Middleware: Проверяет, что пользователь имеет доступ к компании
  • Изоляция данных: Каждая компания видит только свои данные
  • UserCompanyRole: Таблица связей пользователь↔компания↔роль
  • Переключение: Мгновенное переключение между компаниями без повторного входа
  • Безопасность: Невозможно получить доступ к чужим данным
