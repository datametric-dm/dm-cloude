## 🐛 Troubleshooting

**Проблема:** Не вижу данных после входа

**Решение:**
1. Убедитесь, что выбрали компанию (не пропустили экран выбора)
2. Проверьте, что данные созданы: `python scripts/seed_test_data.py`
3. Проверьте консоль браузера на ошибки

**Проблема:** Получаю 403 Forbidden

**Решение:**
1. Проверьте, что пользователь связан с компанией
2. Запустите: `python scripts/create_test_user.py`
3. Перелогиньтесь в системе

**Проблема:** Пустые графики в дашбордах

**Решение:**
- Некоторые дашборды требуют больше данных
- Запустите seed скрипт ещё раз для большего количества данных
- Или подождите - часть графиков показывают тренды за период
