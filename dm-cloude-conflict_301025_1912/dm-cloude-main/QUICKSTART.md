## 🚀 Запуск (выберите один вариант)

### Вариант 1: Автоматический скрипт (рекомендуется)
```bash
cd /app
./start.sh
```

### Вариант 2: Docker Compose
```bash
cd /app
docker-compose up -d
```

### Вариант 3: С проверкой
```bash
cd /app
./verify.sh      # Проверка конфигурации
./start.sh       # Запуск
```

## ❓ Проблемы?

### Порт 80 занят
```yaml
# В docker-compose.yml измените:
nginx:
  ports:
    - "8080:80"  # Вместо 80:80
```

Затем открывайте: http://localhost:8080

### Сервисы не запускаются
```bash
# Посмотрите логи
docker-compose logs

# Пересоздайте
docker-compose down
docker-compose up -d --force-recreate
```
