# DataMetrics Cloud MVP v2.0

> Современная система управления проектами, клиентами, счетами и платежами с интеграцией Telegram Bot

## 🎯 Особенности

- ✅ **Система аутентификации** - JWT токены, защищенные роуты
- ✅ **PostgreSQL база данных** - надежное хранение данных
- ✅ **Alembic миграции** - управление схемой БД
- ✅ **Docker поддержка** - легкое развертывание
- ✅ **React + FastAPI** - современный стек технологий

## ⚡ Быстрый старт

### 1. Настройка .env файлов

После клонирования репозитория, запустите скрипт настройки:

```bash
./setup-env.sh
```

Скрипт создаст все необходимые .env файлы в зависимости от типа развертывания (Docker или локально).

**Альтернативно:** Скопируйте .env.example файлы вручную:

```bash
# Для Docker
cp .env.production .env

# Для локального запуска
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```
